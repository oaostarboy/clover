## Exact interface
new FlowTransport({send(rawString),onMessage(payload,release),onWritable(),onClose(reason),timeoutMs=30000}); .start(); .receive(rawString); .trySend(string|Uint8Array) -> boolean; .close(). trySend false means NOT queued: upstream MUST pause or use a strictly bounded queue, never drop or replay. onWritable may fire when handshake completes and final ACK releases one whole message. onMessage caller calls release exactly once only after downstream bounded admission; retaining unlimited admitted payloads outside core invalidates system bound. close handler must close actual socket. Binary receive is Uint8Array, string fatal UTF8 decoded. Crypto uses global crypto.getRandomValues; RN integration must supply proper polyfill or add injected secure nonce factory, never Math.random.

## Stop-and-wait protocol
V1 JSON ASCII envelopes, strict keys. hello{v:1,t:'hello',g:32lowerhex}; data{v:1,t:'data',g:<last peer grant>,n:<fresh128-bit nonce>,m:<message nonce>,i:<zero-based index>,z:<whole byte length>,b:<binary bool>,f:<final bool>,d:<base64 chunk>}; ack{v:1,t:'ack',n:<data nonce>,g:<new unpredictable receive grant>}.

Initial hello gives a receive grant. Exactly one data chunk outstanding per direction. Receiver must see its grant then consumes it. Next grant only travels in ACK, so a sender cannot generate subsequent valid chunks without actually reading the ACK. Sender validates exact outstanding receipt nonce. Duplicate/forged/unknown receipts, duplicate hello, malformed/oversized frames close; no response amplification. Final ACK withheld until application releases bounded admission. No cumulative traffic quota. Healthy message stream runs indefinitely.

16KiB chunk; wire<=23000ASCII chars; hello/ACK<=192chars. Max original1MiB, preallocated bounded reassembly, one queued original message per direction. One data+one ACK+initial hello can be handed to socket per direction without evidence peer read; native socket/kernel overhead not measured universal bound. Per connection1MiB outgoing copy+1MiB reassembly/admission payload (text decoding/copy adds bounded transient memory); integration budgets must include those and JSON/base64 overhead. Empty/string/binary/Unicode messages tested. Fixed three timer slots hello/send/receive, timeout aborts and clears state; never replenishes credit. Partial assembly timeout and final admission timeout close. Old connection ACK cannot match fresh random nonce in new instance.
